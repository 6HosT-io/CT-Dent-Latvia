How to analyse CBCT

Formats, access methods, DICOM data and real examples.

CT-Dent offers a wide choice of formats at the most favourable prices, using the latest cone-beam CT technology that opens new possibilities in diagnostics and treatment planning.

We will help you get the maximum benefit from your patients' 3D scans. The scan data can be viewed in several ways:

DICOM data: exchange of digital imaging (DICOM) data is a widely used standard in medicine. A DICOM file contains binary data elements with patient and examination metadata — it can be opened by any DICOM-compatible application, including the free iRYS.

  • Free iRYS software
  • 1:1 print
  • E-mail
  • DICOM data for any DICOM application
